STEP 3: PHASE 3 IMPLEMENTATION — MULTIMODAL ML ENGINE (2026-11-06)
================================================================================

CONTEXT:
  User confirmed to proceed with Phase 3. Implemented all 5 sub-phases:
  P3-S1 through P3-S5.

REASONING:
  P3-S1 — Directory setup:
    - Created `backend/api/ml_engine/` package with `__init__.py`.

  P3-S2 & P3-S3 — Preprocessing (`preprocess.py`):
    - Image transform uses standard ImageNet normalization:
      mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225].
    - Resizes to (224, 224) as required by ResNet-50.
    - `.unsqueeze(0)` adds the batch dimension -> `(1, 3, 224, 224)`.
    - `Image.open().convert('RGB')` ensures 3 channels.
    - Clinical data preprocessing: SHA-512 deterministic hash seeding a numpy
      generator producing a 128-d unit-normalized tensor `(1, 128)`.

  P3-S4 — Model architecture (`model.py`):
    - `AnemiaMultimodalNet(nn.Module)`:
      - Two ResNet-50 backbones (conjunctiva, fingernails) with final FC stripped -> 2048-d each.
      - Tabular branch: MLP Linear(128->256) -> ReLU -> Linear(256->128) -> ReLU.
      - Feature concatenation: 2048 + 2048 + 128 = 4224 dimensions.
      - Fusion head: Linear(4224->512) -> ReLU -> Dropout(0.3) -> Linear(512->1) -> Sigmoid.
      - Output: scalar probability [0, 1].

  P3-S5 — Inference logic (`predict.py`):
    - Singleton pattern via `_get_model()` avoids re-initializing weights on every call.
    - Inlined model/record queries to prevent circular imports.
    - Runs in `torch.no_grad()` evaluation mode.

  - All ML engine files compiled cleanly with `py_compile`.
